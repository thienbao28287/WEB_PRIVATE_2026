Công cụ nào trong bài được dùng để soạn thảo mã HTML, CSS và JavaScript?

## git-add

### Câu hỏi
Trong quy trình Git của bài, lệnh nào đưa thay đổi vào vùng staging trước khi commit?

### Lựa chọn
- [ ] `git push`
- [ ] `git branch`
- [x] `git add`
- [ ] `git clone`

### Giải thích
git add đưa nội dung đã sửa vào staging. Sau đó dùng git commit để ghi lại phiên bản và git push để đưa commit lên remote.

### Ôn tập
[Git — Các lệnh cơ bản](theory.md#1-git)

## git-push

### Câu hỏi
Sau khi đã add và commit thay đổi, lệnh nào đẩy commit lên nhánh main của remote origin?

### Lựa chọn
- [ ] `git init`
- [ ] `git status`
- [ ] `git pull origin main`
- [x] `git push origin main`

### Giải thích
git push origin main đẩy commit của nhánh main lên origin. git pull lấy và tích hợp thay đổi từ remote về máy.

### Ôn tập
[Git — Đẩy và lấy dữ liệu](theory.md#1-git)

## github-pages

### Câu hỏi
Để xuất bản trang HTML bằng GitHub Pages theo hướng dẫn, bạn cần làm gì?

### Lựa chọn
- [ ] Chỉ lưu index.html trên máy là đủ
- [x] Đẩy mã lên GitHub và chọn đúng nguồn xuất bản trong Settings → Pages
- [ ] Chỉ cài extension Prettier
- [ ] Đổi tên index.html thành index.txt

### Giải thích
Cần đưa mã lên repository, cấu hình nguồn xuất bản của Pages rồi đợi triển khai thành công. Lưu tệp trên máy chưa làm website online cập nhật.

### Ôn tập
[GitHub Pages](theory.md#2-github)
